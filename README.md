## 🚀 Featured Projects

### 🔗 [LingoSwap — Language Learning via Video Call](https://github.com/La1do/UI_Web-LingoSwap)
A web application that connects language learners through random video calls — like Omegle, but focused on foreign language practice.

**Tech Stack:**
🧩 Frontend: React 19, TypeScript, Vite, TailwindCSS v4, React Router v7  
⚡ Realtime: Socket.IO (matching queue, chat, WebRTC signaling)  
📹 Video: WebRTC P2P  
🔐 Auth: JWT + Google OAuth  

---

### 🔗 [Habit Ledger — Backend Service](https://github.com/La1do/habit-ledger)
A backend service for habit tracking and management, built with a modern Node.js + TypeScript stack.

**Tech Stack:**  
🔧 Backend: Node.js, TypeScript  
🗄️ Database: PostgreSQL  

---

### 🔗 [CV Website](https://github.com/HauiZ/Cv-Website) · [Backend](https://github.com/HauiZ/Backend_CVW)
A full-stack web application for building and managing CVs with modern design and real-time preview.

**Tech Stack:**  
🧩 Frontend: ReactJS, TailwindCSS  
🔧 Backend: ExpressJS  
🗄️ Database: SQL Server
